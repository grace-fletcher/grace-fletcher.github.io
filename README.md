## Enhancement One - Software Design and Engineering
The artifact I chose for the Software Design and Engineering enhancement was my final project from CS 330: Computer Graphics and Visualization. This project was created around October of 2025. I selected this item for my ePortfolio as I felt it was a good representation of what software design and engineering is. Some specific components of the artifact that showcase my skills and abilities in software development would include the implementation of OpenGL in a C++ project, drawing and rendering 3D shapes in a 3D scene, and using inheritance as well as encapsulation to protect data and create reusable code.  

This artifact was improved with the addition of a skybox. A skybox uses a “cubemap” to create what visually looks like a dynamic background for the 3D scene. A cubemap is a texture file that contains six standalone 2D faces that come together to form a cube. I met the course outcomes I planned to meet with this enhancement in Module One.

I felt that the process of enhancing and modifying the project to be beneficial to my learning as a whole. For example, I learned how to properly render and draw a skybox using OpenGL libraries for a 3D scene, and I feel that that can be applied to later projects should I choose a career in the computer graphics and visualization field. I also learned how to do this while working with existing code.

## Enhancement Three - Databases
The artifact used for this enhancement is a CRUD Python module designed to help maintain and manage an animal shelter’s database of rescued animals. It was my final project for CS 340: Client/Server Development. It was created around October 2025. I chose to include this artifact in my ePortfolio as I think it perfectly showcases my abilities when it comes to working with SQL databases and creating Python scripts to run queries on those databases. I improved this artifact by implementing more complex and dynamic SQL query functions in the CRUD Python module. Specifically, I added an insertMany() method, an updateOne() method, a deleteOne() method, and a count() method. I also added additional input validation to this project, and I got rid of any redundant in-line comments in the code that were no longer needed. I also was able to get the database running on my local machine.  

I met the course outcomes I planned to meet with this enhancement in Module One. Since I added additional and more in-depth input validation to this project, I also ended up improving the security of this project, which wasn't a part of my initial planning for this artifact.  

I felt that the development process of improving this artifact was relatively straightforward. I learned that there are a bunch of options when it comes to SQL querying methods, and that you can do a lot with those methods in a python development environment. The only challenge I faced was getting the database working on my pc, since I had to download a bunch of software that was hardwired into the virtual environment I used initially when creating this project in October 2025. After overcoming this challenge, I now know everything that is needed in order to run and manage SQL databases on a local machine.
