## Enhancement One - Software Design and Engineering
&emsp;The artifact I chose for the Software Design and Engineering enhancement was my final project from CS 330: Computer Graphics and Visualization. This project was created around October of 2025. I selected this item for my ePortfolio as I felt it was a good representation of what software design and engineering is. Some specific components of the artifact that showcase my skills and abilities in software development would include the implementation of OpenGL in a C++ project, drawing and rendering 3D shapes in a 3D scene, and using inheritance as well as encapsulation to protect data and create reusable code.  

&emsp;This artifact was improved with the addition of a skybox. A skybox uses a “cubemap” to create what visually looks like a dynamic background for the 3D scene. A cubemap is a texture file that contains six standalone 2D faces that come together to form a cube. I met the course outcomes I planned to meet with this enhancement in Module One.

&emsp;I felt that the process of enhancing and modifying the project to be beneficial to my learning as a whole. For example, I learned how to properly render and draw a skybox using OpenGL libraries for a 3D scene, and I feel that that can be applied to later projects should I choose a career in the computer graphics and visualization field. I also learned how to do this while working with existing code.
